# CS-300-Danny-Hall
What was the problem you were solving in the projects for this course?

The main problem I was solving was finding an efficient way to store and organize course information for ABCU. The program needed to load course information from a file, print the courses in alphanumeric order, and allow a user to search for a specific course and see its prerequisites. In Project One, I compared a vector, hash table, and binary search tree to see how each one would handle these tasks. In Project Two, I used what I learned to build a working C++ program that could load and display the course information.

How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by looking at what the program needed to do and then comparing the different data structures we learned about during the course. Each data structure has advantages and disadvantages depending on how the information needs to be used. For example, a hash table can make searching fast, while a binary search tree can make it easier to keep information in order. Understanding these differences helped me see that choosing a data structure is not just about getting a program to work. The choice can also affect how efficiently the program searches, sorts, and stores information.

How did you overcome any roadblocks you encountered while going through the activities or project?

One of the biggest challenges was understanding how the different data structures actually behaved once I started working with them in code. I ran into problems with loading files, inserting and removing data, sorting information, and getting the output to match what was expected. I worked through these problems by testing one part of the program at a time instead of trying to fix everything at once. This made it easier to find where something was going wrong and make changes without creating new problems somewhere else.

How has your work on this project expanded your approach to designing software and developing programs?

Before this course, I was more focused on whether a program worked and produced the correct result. These projects made me think more about what is happening behind the program and how the way data is organized can affect performance. I now have a better understanding of why it is important to plan how information will be stored and accessed before writing the entire program. Comparing the vector, hash table, and binary search tree also showed me that there can be several ways to solve the same problem, and the best solution depends on what the program needs to do.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

This course has also made me pay more attention to how I organize my code. Breaking the program into separate functions made it easier to understand what each part was responsible for and made troubleshooting much easier. I also used descriptive names and comments so that someone looking at the code later could understand what it was doing. I have learned that readable and organized code is easier to test, fix, and change, which becomes more important as programs get larger and more complicated.
